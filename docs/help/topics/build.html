Build

ビルド

.NET SDK を使って CLI をビルドします。

必要なもの

  • .NET 8 SDK
  • Windows の HTML Help Viewer で確認する場合は hh.exe
  • 生成した CHM を開く Windows 環境

Debug ビルド

開発中は通常の dotnet build で十分です。

dotnet build .\src\hhc\hhc.csproj

Debug ビルドでは次の実行ファイルが生成されます。

src\hhc\bin\Debug\net8.0\hhc.exe

Release ビルド

配布や手元のツール置き場へコピーする場合は Release ビルドを使います。

dotnet build .\src\hhc\hhc.csproj -c Release

実行ファイルは次に生成されます。

src\hhc\bin\Release\net8.0\hhc.exe

動作確認

ビルド後にバナーとヘルプを確認します。

.\src\hhc\bin\Debug\net8.0\hhc.exe --version
.\src\hhc\bin\Debug\net8.0\hhc.exe --help

自己ヘルプを生成する

このヘルプファイルも同じコンパイラで生成できます。

.\src\hhc\bin\Debug\net8.0\hhc.exe .\docs\help\KomuraHhc.hhp --verbose

成功すると docs\help\KomuraHhc.chm が更新されます。
