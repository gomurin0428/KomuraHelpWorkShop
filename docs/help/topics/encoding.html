Encoding

日本語と文字コード

HTML 本文、HHP、HHC、HHK の文字コードの扱いです。

推奨設定

日本語のヘルプでは HHP に次を指定してください。

Language=0x0411 Japanese

この指定により、目次、索引、内部タイトルなど HTML Help Viewer が ANSI として読む情報を CP932 で格納します。

読み込み時の判定

HHP、HTML、CSS、HHC、HHK のテキストは次の順に判定します。

  1. UTF-8 BOM、UTF-16 LE、UTF-16 BE の BOM があればそれを使う。
  2. BOM がなくても UTF-8 として正しく読める場合は UTF-8 として読む。
  3. UTF-8 として読めない場合は、現在の Windows ANSI コードページとして読む。

CHM への格納

種類格納時の扱い
HTML / CSS / 画像元ファイルのバイト列をそのまま格納します。HTML には <meta charset="utf-8"> などを明示してください。
HHC / HHK読み込んだテキストを Language の ANSI コードページへ変換して格納します。
内部文字列タイトル、既定トピック、目次ファイル名、索引ファイル名などを同じ ANSI コードページで書き込みます。

文字化けを避けるコツ

  • ソースファイルは UTF-8 で統一する。
  • HTML 本文には <meta charset="utf-8"> を入れる。
  • 日本語の HHP には Language=0x0411 Japanese を入れる。
  • 目次と索引の表示名は HHC/HHK の Name に書く。
  • 生成後に文字化けする場合は、CHM を閉じてから再コンパイルする。
