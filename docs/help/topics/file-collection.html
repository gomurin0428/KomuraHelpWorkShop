Files and Paths

ファイル収集とパス

CHM に入るファイルの決まり方と、相対パスの解決規則です。

必ず収集するファイル

  • [FILES] に列挙されたファイル
  • Contents file で指定された .hhc
  • Index file で指定された .hhk
  • Default topic で指定された HTML

これらが欠落している場合はコンパイル失敗になります。--allow-missing を指定した場合だけ警告として続行します。

リンク収集

既定では、収集済みファイルの中を読み、次の参照先を追加します。

対象収集する参照
HTMLhref と src
CSSurl(...) と @import "file.css"
HHC / HHK<param name="Local" value="...">

--no-link-scan を指定するとリンク収集を止め、明示されたファイルだけを格納します。

無視するリンク

次のような外部リンクや CHM 内ジャンプは、ローカルファイルとして収集しません。

  • http:、https:、ftp:
  • mailto:、tel:、javascript:、data:
  • mk:@MSITStore:、ms-its:、its:
  • #section のような同一ページ内アンカー

page.html#section や page.html?x=1 は、ファイル部分だけを取り出して page.html として扱います。

相対パスの基準

パスの出所基準ディレクトリ
[FILES]、Contents file、Index file、Default topicHHP ファイルがあるディレクトリ
HTML / CSS / HHC / HHK 内のリンクリンクを書いたファイルがあるディレクトリ
絶対パスディスク上の絶対パス。ただし CHM 内ではファイル名または HHP からの相対パスに正規化します。

CHM 内のアーカイブパス

HHP の下にあるファイルは、HHP からの相対パスで CHM に入ります。たとえば docs\help\topics\usage.html は topics/usage.html になります。

Flat=yes を指定すると、フォルダーを落としてファイル名だけで格納します。HTML、CSS、HHC、HHK 内のローカル参照もファイル名だけに書き換えます。同名ファイルがあるプロジェクトでは重複しやすいため注意してください。

確認方法

hhc help.hhp --verbose

add: topics/usage.html <- C:\...\topics\usage.html のように、CHM 内のパスと元ファイルの対応を確認できます。
