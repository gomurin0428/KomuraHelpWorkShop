Troubleshooting

トラブルシュート

生成した CHM が期待どおりに表示されない場合の確認項目です。

本文だけの画面になる

#WINDOWS、#STRINGS、Contents file の情報が不足すると、HTML Help Viewer はナビゲーションペインなしで開くことがあります。

バージョン 0.1.1 以降では既定ウィンドウと簡易 TOC の生成を追加しています。古い生成物は再コンパイルしてください。

ファイルが表示されない

  • [FILES] に含まれるパスが HHP からの相対パスになっているか確認します。
  • リンク収集を無効化していないか確認します。
  • --verbose を付けて、収集されたファイル一覧を確認します。

Windows でブロックされる

インターネットから取得した CHM は Windows によってブロックされることがあります。ファイルのプロパティからブロック解除してから開いてください。

中身を確認する

hh.exe -decompile out-dir file.chm

展開できれば、CHM コンテナとしては HTML Help Viewer に認識されています。
