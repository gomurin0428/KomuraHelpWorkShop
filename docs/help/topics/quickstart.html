Quick Start

クイックスタート

最小の HHP、HTML、TOC を用意して CHM を生成する流れです。

1. フォルダーを用意する

my-help\
  help.hhp
  index.html
  toc.hhc
  styles\
    help.css

2. HHP を書く

[OPTIONS]
Compiled file=MyHelp.chm
Contents file=toc.hhc
Default topic=index.html
Language=0x0411 Japanese
Title=My Help

[FILES]
index.html
styles\help.css

Language=0x0411 Japanese は、日本語の目次や索引を Windows の HTML Help Viewer で正しく表示するために重要です。

3. HTML を書く

<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <title>My Help</title>
  <link rel="stylesheet" href="styles/help.css">
</head>
<body>
  <h1>My Help</h1>
  <p>最初のトピックです。</p>
</body>
</html>

4. TOC を書く

<!DOCTYPE HTML PUBLIC "-//IETF//DTD HTML//EN">
<html>
<body>
<ul>
  <li><object type="text/sitemap">
    <param name="Name" value="概要">
    <param name="Local" value="index.html">
  </object></li>
</ul>
</body>
</html>

5. コンパイルする

hhc my-help\help.hhp --verbose

成功すると my-help\MyHelp.chm ができます。生成後は 検証と配布 の手順で中身を確認してください。
