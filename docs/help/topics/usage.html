Usage

使い方

HHP プロジェクトを指定して CHM を生成します。

基本形

hhc <project.hhp> [--out <file.chm>] [options]

サンプルをコンパイルする

.\src\hhc\bin\Debug\net8.0\hhc.exe .\examples\basic\help.hhp

オプション

オプション説明
-o, --out <path>[OPTIONS] の Compiled file を上書きします。
--no-link-scan明示されたファイルだけを格納します。
--allow-missing入力ファイル欠落を警告にして CHM を生成します。
-v, --verbose収集したファイルを表示します。
--versionバージョン情報を表示します。
