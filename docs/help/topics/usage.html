Usage

使い方

HHP プロジェクトを指定して CHM を生成します。

基本形

hhc <project.hhp> [--out <file.chm>] [options]

一度にコンパイルできる HHP は 1 つです。HHP の相対パスは、HHP ファイルがあるディレクトリを基準に解決されます。

よく使うコマンド

目的コマンド
通常の生成hhc help.hhp
出力先を指定hhc help.hhp --out dist\help.chm
収集されたファイルを確認hhc help.hhp --verbose
明示ファイルだけを格納hhc help.hhp --no-link-scan
欠落ファイルを警告にするhhc help.hhp --allow-missing

オプション

オプション説明
-o, --out <path>[OPTIONS] の Compiled file を上書きします。相対パスは HHP のディレクトリを基準に解決します。
--no-link-scan[FILES]、Contents file、Index file、Default topic で明示されたファイルだけを格納します。
--allow-missing入力ファイル欠落を警告にして CHM を生成します。配布前の最終生成では外すことを推奨します。
-v, --verbose追加したアーカイブパスと元ファイルの対応を標準エラーへ表示します。
--versionバージョン情報を表示します。
-h, --help, /?コマンドラインヘルプを表示します。

終了コード

コード意味主な原因
0成功CHM が生成されました。
1コンパイル失敗HHP が見つからない、必須ファイルが欠落している、出力先へ書き込めない。
2コマンドライン引数の誤り未知のオプション、HHP 未指定、HHP を複数指定した。

サンプルをコンパイルする

.\src\hhc\bin\Debug\net8.0\hhc.exe .\examples\basic\help.hhp --verbose

生成した CHM の確認手順は 検証と配布 を参照してください。
