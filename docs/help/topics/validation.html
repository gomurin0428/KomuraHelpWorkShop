Validation

検証と配布

生成した CHM を配布前に確認するための手順です。

基本チェック

  1. --verbose を付けてコンパイルし、必要な HTML、CSS、画像、HHC、HHK が追加されているか見る。
  2. CHM を開き、タイトル、目次、索引、既定トピックを確認する。
  3. 主要なページをクリックし、リンク切れや画像抜けがないか確認する。
  4. 日本語の目次と索引が文字化けしていないか確認する。

decompile で中身を見る

Windows の hh.exe は CHM の展開にも使えます。

hh.exe -decompile artifacts\decompiled docs\help\KomuraHhc.chm

展開先に HTML、CSS、toc.hhc、index.hhk が出てくれば、CHM コンテナとして読み取れています。

警告の扱い

警告確認すること
file not foundHHP からの相対パス、またはリンク元ファイルからの相対パスが正しいか確認します。
No Contents file was specified簡易 TOC が生成されています。手作りの目次が必要な場合は Contents file を指定します。
Full-text search index generation is not implemented検索タブ用の全文検索インデックスは生成されません。
Binary TOC / Binary Indexバイナリ化せず、HHC/HHK のソースを格納します。

配布時の注意

  • Web からダウンロードした CHM は Windows にブロックされることがあります。
  • 配布前の最終生成では --allow-missing を使わず、欠落ファイルを失敗として扱うことを推奨します。
  • CHM を開いたまま再生成すると、ビューア側が古い内容を保持しているように見えることがあります。確認時は一度閉じて開き直してください。
