Project Format

HHP プロジェクト形式

HTML Help Workshop の HHP 形式のうち、基本的なプロジェクト設定を読み取ります。

対応する OPTIONS

  • Compiled file
  • Contents file
  • Index file
  • Default topic
  • Default Window
  • Default Font
  • Title
  • Language
  • Flat

リンク収集

既定では、明示されたファイルに加えて、HTML の href / src、CSS の URL 参照、HHC/HHK の Local param から参照ファイルを収集します。

リンク収集を止めたい場合は --no-link-scan を指定します。

TOC がない場合

Contents file が指定されていない場合は、HTML ファイル一覧から Table of Contents.hhc を自動生成します。
