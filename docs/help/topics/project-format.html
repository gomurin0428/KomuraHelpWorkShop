Project Format

HHP プロジェクト形式

HTML Help Workshop の HHP 形式のうち、CHM 生成に必要な基本設定を読み取ります。

最小構成

日本語ヘルプを作る場合は、まず次の形から始めると確認しやすくなります。

[OPTIONS]
Compatibility=1.1 or later
Compiled file=MyHelp.chm
Contents file=toc.hhc
Index file=index.hhk
Default topic=index.html
Language=0x0411 Japanese
Title=My Application Help

[FILES]
index.html
topics\usage.html
styles\help.css

対応する OPTIONS

項目説明
Compiled file出力する CHM ファイル名です。省略時は HHP と同じ名前の .chm になります。
Contents file左ペインの目次として使う .hhc です。省略時は簡易 TOC を自動生成します。
Index fileキーワードタブとして使う .hhk です。省略できます。
Default topicCHM を開いたときに最初に表示する HTML です。
Default Window#WINDOWS に書き込む既定ウィンドウ名です。省略時は main です。
Default FontHTML Help Viewer に渡す既定フォント情報です。
TitleHTML Help Viewer のタイトルに使います。
LanguageLCID と言語名です。日本語では 0x0411 Japanese を指定します。
Flatyes の場合、CHM 内のアーカイブパスをファイル名だけにします。

読み取り規則

  • セクション名とオプション名は大文字小文字を区別しません。
  • 空行と、行頭が ; の行は無視します。
  • [OPTIONS] は key=value 形式で読み取ります。
  • [FILES] 以外のセクションも読み込みますが、多くは CHM 生成には使いません。
  • 値全体を一重引用符または二重引用符で囲んだ場合は、外側の引用符を取り除きます。

TOC と Index

Contents file と Index file は HTML Help Workshop と同じ text/sitemap の HTML 形式です。各項目の Name が表示名、Local が開くトピックです。

<li><object type="text/sitemap">
  <param name="Name" value="使い方">
  <param name="Local" value="topics/usage.html">
</object></li>

日本語の目次や索引が文字化けする場合は 日本語と文字コード を確認してください。
