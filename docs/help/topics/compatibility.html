Compatibility

互換性と制限

最初の目標は、Windows の HTML Help Viewer で開ける CHM を生成することです。

対応済み

  • ITSF v3 / ITSP / PMGL / PMGI ディレクトリ生成
  • 非圧縮 CHM コンテナ生成
  • #SYSTEM、#WINDOWS、#STRINGS、#ITBITS、::DataSpace/NameList 生成
  • TOC / Index ソースファイルの格納
  • 多ファイルプロジェクト用の PMGI root 生成

未対応

  • LZX 圧縮
  • 全文検索インデックス $FIftiMain
  • Binary TOC / Binary Index
  • CHI / CHW / merged help collection generation
