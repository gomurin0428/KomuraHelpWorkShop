Compatibility

互換性と制限

最初の目標は、Windows の HTML Help Viewer で開ける CHM を生成することです。

対応済み

分類対応内容
CHM 形式ITSF v3 / ITSP / PMGL / PMGI ディレクトリを生成します。ファイル数が多い場合は PMGI root も生成します。
格納方式非圧縮 CHM コンテナを生成します。LZX 圧縮は使いません。
内部ファイル#SYSTEM、#WINDOWS、#STRINGS、#ITBITS、::DataSpace/NameList を生成します。
ナビゲーションTOC / Index のソースファイルを格納し、HTML Help Viewer の目次タブとキーワードタブで使えるようにします。
文字コードLanguage の LCID から ANSI コードページを選び、HHC/HHK と内部文字列を変換します。

未対応または簡略化

機能現在の動作
LZX 圧縮未対応です。生成物は大きくなりますが、構造確認や小中規模ヘルプの配布には使えます。
全文検索インデックス$FIftiMain は生成しません。Full-text search=Yes は警告になります。
Binary TOC / Binary Indexバイナリ化せず、元の .hhc / .hhk を格納します。指定がある場合は警告を出します。
Merge Files[MERGE FILES] は検出しますが、結合ヘルプコレクションは生成しません。
CHI / CHW外部インデックスやコレクション用ファイルは生成しません。

Microsoft hhc.exe との違い

この実装は、HTML Help Workshop の完全な再実装ではなく、CHM を開くために必要な中核部分を先に実装しています。そのため、検索品質、圧縮率、古いプロジェクトの細かな互換設定まで一致させる目的にはまだ向きません。

一方で、ビルド環境に HTML Help Workshop をインストールできない場合や、HHP から CHM を自動生成したい場合の代替コンパイラとして使えます。
