Komura Help Workshop

Komura HTML Help Compiler

Microsoft HTML Help Workshop の hhc.exe と同じ用途で使う、ローカル実装の CHM コンパイラです。

このヘルプで分かること

この CHM は Komura HTML Help Compiler 自身で生成されています。HHP プロジェクトの作り方、コマンドラインの使い方、ファイル収集の規則、日本語の文字コード、生成物の確認方法をまとめています。

最初に試す場合は クイックスタート から進めてください。既存の HHP を移植する場合は HHP プロジェクト形式 と ファイル収集とパス が入口になります。

主な機能

領域内容
プロジェクト.hhp の [OPTIONS]、[FILES]、Contents file、Index file、Default topic を読み取ります。
リンク収集HTML の href / src、CSS の url(...)、HHC/HHK の Local から参照ファイルを追加します。
ビューア設定#SYSTEM、#WINDOWS、#STRINGS を生成し、HTML Help Viewer のタイトル、既定トピック、目次、索引を設定します。
日本語Language の LCID に合わせて HHC/HHK と内部文字列を ANSI コードページへ変換します。日本語は通常 0x0411 Japanese です。
CHM コンテナITSF v3 / ITSP / PMGL / PMGI の非圧縮 CHM を生成します。

読み進める順番

  1. クイックスタート で最小のプロジェクトを作る。
  2. ビルド で実行ファイルを用意する。
  3. 使い方 でオプションと終了コードを確認する。
  4. 検証と配布 で生成した CHM を確認する。

この版の位置づけ

このコンパイラは、まず Windows の HTML Help Viewer で開ける CHM を安定して生成することを優先しています。LZX 圧縮、全文検索インデックス、Binary TOC / Binary Index はまだ実装していません。詳しくは 互換性と制限 を参照してください。
