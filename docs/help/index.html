Komura Help Workshop

Komura HTML Help Compiler

Microsoft HTML Help Workshop の hhc.exe と同じ用途で使う、ローカル実装の CHM コンパイラです。

このヘルプについて

この CHM は、Komura HTML Help Compiler 自身で生成されています。HHP プロジェクトを読み込み、HTML、TOC、Index、CSS などを非圧縮 CHM コンテナへ格納します。

まず試す

  1. ビルドする
  2. サンプル HHP をコンパイルする
  3. 表示に問題がある場合の確認をする

主な機能

  • .hhp の [OPTIONS] と [FILES] を読み取ります。
  • .hhc / .hhk / HTML / CSS からリンク先ファイルを収集します。
  • #SYSTEM、#WINDOWS、#STRINGS を生成し、HTML Help Viewer の基本表示を構成します。
  • ファイル数が多いプロジェクト向けに PMGI / PMGL ディレクトリを生成します。
